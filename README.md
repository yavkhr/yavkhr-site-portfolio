# Obod Peter — Portfolio Website

Welcome to my portfolio website! This is my personal site where I show my work as a **Python Developer**.

## What is on the site

- **Home** — my name, my job (Python Developer), and the things I make: TG Bots, Parsers, AI Assistants
- **About me** — a little about me and what I do
- **Projects** — my projects from GitHub (for example, my Telegram AI Assistant bot)
- **How to reach me** — how to contact me

## What I used to build it

This site is a simple **static website**. It has only 3 files:

- `index.html` — the main page (the structure)
- `styles.css` — the styles (colors, fonts, animation)
- `script.js` — the logic (language switch EN/RU, navigation)

### Technologies

| Technology | What I used it for |
|---|---|
| **HTML** | The structure of the page |
| **CSS** | Colors, fonts, dark theme, stars animation, hover effects |
| **JavaScript** | Language switch (EN/RU), page navigation, project cards |
| **Google Fonts** | Fonts: Unbounded, Space Grotesk, JetBrains Mono |
| **GitHub Pages** | Free hosting for the site |

## How to run it

1. Download or clone this repository
2. Open `index.html` in your browser
3. That's it — no install needed!

## How to update it

1. Change a file (for example `index.html`)
2. Commit and push to GitHub
3. Wait about 1 minute — the site updates by itself
